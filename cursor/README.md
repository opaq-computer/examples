# Cursor

1. Settings → Models → **OpenAI API Key**: paste your Opaq key (`opaq_sk_...`).
2. Enable **Override OpenAI Base URL** and set it to `https://opaq.computer/v1`.
3. Add a custom model with a full id from the catalog, for example `anthropic/claude-sonnet-5.5` or `deepseek/deepseek-v4.1-flash`.

Requests from chat and inline edits then go through Opaq and are paid from your sealed balance.
